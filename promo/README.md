# Vidéos de promotion

Vidéos de motion design en arabe pour présenter data-dz sur les réseaux sociaux.

| Fichier | Format | Durée | Usage |
|---|---|---|---|
| `data-dz-promo-ar-vertical.mp4` | 1080 × 1920 (9:16) | 29 s | TikTok, Instagram Reels, YouTube Shorts, stories |
| `data-dz-promo-ar-horizontal.mp4` | 1920 × 1080 (16:9) | 42 s | YouTube, LinkedIn, Facebook, présentations |

## Contenu

- **Verticale** : accroche (« des données fiables sur l'Algérie ? »), le vrai site sur un téléphone, les fonctionnalités (rechercher, prévisualiser, télécharger, source et licence), la communauté (proposer, voter, commenter, suivre), puis data-dz.com.
- **Horizontale**, plus rythmée (montage calé sur 120 BPM) : le vrai site avec son globe, une carte de l'Algérie avec 11 chefs-lieux, les 13 catégories du catalogue, l'intérêt pour les projets d'études (mémoires, recherche, programmation, analyse de données), puis data-dz.com.

## Sources et droits

- Captures : interface réelle du site, sans aucun chiffre ni jeu de données inventé.
- Carte : contours Natural Earth (domaine public, paquet `world-atlas` déjà utilisé par le globe du site).
- Polices : Cairo et Tajawal (SIL Open Font License).
- Icônes : Lucide (licence ISC), les mêmes que sur le site.
- Musique : composition originale générée par synthèse, sans échantillon externe ni droits à payer.

Ces fichiers ne font pas partie du site : ils sont exclus des déploiements Vercel (`.vercelignore`).
